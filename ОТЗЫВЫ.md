# Оценки, лайки и отзывы через Telegram

Свой сервер не нужен. Есть статический сайт на GitHub Pages, бот в Telegram и GitHub Action, который раз в 15 минут забирает из бота новое и записывает в репозиторий `data/ratings.json`.

## Три варианта, коротко

| | (а) Канал + опрос + Post Widget | (б) Бот + GitHub Actions | (в) Giscus (GitHub Discussions) |
|---|---|---|---|
| Оценка 1–5 | опрос под постом; голоса анонимны, сайт их прочитать не может | бот получает звёзды прямо из ссылки сайта; на плитках средняя оценка | только реакции 👍, звёзд нет |
| Отзыв | комментарии в группе, на сайте их показывает виджет Telegram | сообщение боту → текст на витрине | комментарий на сайте |
| Цифры на плитках | нет | да, из `ratings.json` | нет |
| Кто может оставить | все с Telegram | все с Telegram | только те, у кого есть GitHub |
| Работа Паши | канал, группа, посты по каждой игре | бот, два секрета в репозитории | включить Discussions |
| Минус | красиво, но на витрине ни одной цифры | ответ бота приходит с задержкой до 15 минут | аудитория игр в GitHub не живёт |

## Выбор: (б) как основа, канал из (а) — по желанию

**Почему так.** Только бот даёт цифры на витрине: средняя оценка на плитке, столбики 5…1, тексты отзывов. Канал не обязателен, но с ним появляются публичные лайки (реакции на пост игры) и живое обсуждение под постом, которое витрина встраивает виджетом. Giscus остаётся запасным вариантом, если Telegram заблокируют или он надоест.

### Как это выглядит для игрока

1. **♥ Лайк.** Сердечко на плитке, на странице игры и в ленте Shorts. Одно касание — игра в разделе «Избранное». В браузере избранное хранится локально. В Telegram Mini App оно лежит в облаке Telegram (`CloudStorage`) и одинаковое на телефоне и компьютере. Число рядом с сердечком — реакции на пост игры в канале плюс твоё.
2. **★ Оценка и отзыв.** Кнопка «Оценить» открывает окно с пятью звёздами. «Отправить через Telegram» ведёт в бота по ссылке `t.me/<бот>?start=r_<игра>_<звёзды>`. Telegram сам отправляет боту команду, в которой уже есть игра и звёзды. Игрок ничего не печатает, голос засчитан. Бот просит пару слов, и следующее сообщение становится отзывом.
3. **Обсуждение.** Если у игры есть пост в канале, на её странице виден виджет комментариев, а в окне отзыва есть кнопка «Обсуждение под постом».

Один человек — один голос на игру: повторная оценка перезаписывает прежнюю. В репозиторий не попадают ни id, ни ники, только солёный хеш. Публично видны имя (first name) и текст отзыва.

### Модерация

Если указать свой Telegram id в `TG_ADMIN_ID`, бот пересылает Паше каждый новый отзыв с номером. Ответ `/hide 12` скрывает отзыв при следующей синхронизации.

### Задержка

Telegram хранит необработанные обновления сутки, Action забирает их раз в 15 минут (GitHub иногда задерживает расписание). Поэтому бот отвечает «засчитано» не сразу, а в течение 15–30 минут. Голос не теряется. Если мгновенный ответ станет важен, нужен вебхук, а это уже бесплатный Cloudflare Worker, то есть маленький сервер. Пока не нужно.

## Что сделать руками (после твоего «да» на публикацию)

1. **Бот.** В @BotFather: `/newbot`, имя «Betamodern Games», username вроде `BetamodernGamesBot`. Сохрани токен.
   - Не бери Вайбота из Vibe City: два потребителя `getUpdates` на одном токене будут воровать друг у друга обновления.
   - `/setdescription` и `/setuserpic` — логотип из `assets/logo-512.png`.
2. **Mini App.** В @BotFather: `/mybots` → бот → Bot Settings → Menu Button → ссылка на витрину (`https://pavel-cherkun.github.io/<репо>/`), текст «Игры». По желанию `/newapp`, тогда будет красивая ссылка `t.me/<бот>/games`.
3. **Канал (по желанию, для лайков и обсуждений).** Создай канал, привяжи к нему группу для комментариев. Добавь бота админом канала, достаточно права «читать». По посту на игру: обложка, хук, ссылка на страницу игры. Номер поста впиши в `games.json` → `tg.post`, например `"betamodern/12"`.
4. **Репозиторий.** Settings → Secrets and variables → Actions:
   - секрет `TG_BOT_TOKEN` — токен бота;
   - секрет `TG_SALT` — любая длинная случайная строка;
   - переменная `TG_ADMIN_ID` — твой числовой id (узнать у @userinfobot), если нужна модерация.
5. **games.json** → `catalog.telegram`: `"bot": "BetamodernGamesBot"`, `"channel": "betamodern"` (если есть). После этого на сайте оживают кнопки «Отправить через Telegram» и «Канал в Telegram».
6. Вкладка Actions → «Оценки из Telegram» → Run workflow, чтобы проверить первый прогон.

## Файлы

- `tools/telegram-sync.mjs` — синхронизация, без зависимостей, Node 22. Проверен на имитации Telegram: голос, перезапись голоса, отзыв после звёзд, сообщение без звёзд.
- `.github/workflows/telegram.yml` — расписание раз в 15 минут, коммитит только при изменениях.
- `data/ratings.json` — то, что читает сайт. `data/tg-state.json` — сырьё синхронизации, появится после первого прогона.
- `data/ratings.sample.json` — демо-данные; на сайте видны только с `?demo=1`.
